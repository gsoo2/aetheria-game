# 도트 제국: 시간의 군주

2.5D 도트 그래픽의 세계 정복 땅따먹기 게임입니다. 빌드 없이 브라우저에서 바로 실행됩니다.

## 실행

```bash
cd conquest
python3 -m http.server 8000   # 또는 npx serve .
# 브라우저에서 http://localhost:8000 열기
```

`index.html`을 파일로 바로 열어도 동작하지만, 일부 브라우저는 로컬 글꼴 로딩을 막으므로 간단한 서버를 권장합니다.

## 게임 흐름

1. **시간의 성 (RPG 허브)** — 방향키·WASD 또는 클릭/터치로 걸어 다닙니다.
   - 재상 오르벤: 출정, 원정 이어하기, 전략 설명
   - 벽의 세계지도 그림: 다가가면 그림 속 세계로 들어갑니다
   - 상인 미라: 왕실 금화로 소모품과 유물 구입
   - 보물상자: 유물 장착(최대 3개), 소모품 가방 확인
   - 기사단장: 원정 기록 / 서가: 전략서
2. **군주 선택** — 세계지도 위 역사 인물 18명(8명 기본 해금, 나머지는 금화로 해금) 중 고르거나, 이름·나라·칭호·얼굴·재능을 정해 **새 군주를 창조**합니다. 목표(패권 12% / 대제국 30% / 세계 정복 100%)와 난이도를 고릅니다.
3. **그림 속으로** — 성 카메라가 지도 그림 안으로 빨려 들어가고, 세계 지도로 내려앉습니다.
4. **색칠** — 깃발 색을 고르고 시작 땅을 칠합니다. 새 군주는 지도에서 원하는 나라를 직접 고릅니다.
5. **전략 (턴제)** — 영토를 눌러 징병·개발·요새, 인접 영토를 눌러 이동·공격합니다. 다른 나라는 선전포고 후 공격할 수 있고, 평화 제안도 가능합니다. 바다 항로(점선)를 건너면 공격력이 줄어듭니다. 크게 밀린 작은 나라는 항복해 통째로 넘어옵니다.
6. **귀환** — 목표를 달성하거나, 패배하거나, 스스로 철수하면 왕실 금화를 들고 성으로 돌아옵니다. 남은 소모품은 보물창고로 돌아갑니다. 진행 중인 원정은 턴마다 자동 저장되며 성으로 돌아갔다가 이어서 할 수 있습니다.

## 아이템

| 종류 | 이름 | 효과 |
|---|---|---|
| 소모품 | 전쟁의 뿔피리 | 이번 턴 공격력 +50% |
| 소모품 | 황금 상자 | 금 +400 |
| 소모품 | 징병 칙서 | 내 영토에 병력 +2,500 |
| 소모품 | 평화의 비둘기 | 전쟁 상대와 즉시 휴전 |
| 소모품 | 첩자의 단검 | 적 영토 병력 -60% |
| 소모품 | 공성 투석기 | 이번 턴 요새 무시 |
| 유물 | 군신의 깃발 / 거인의 방패 / 상인의 저울 / 선왕의 왕관 / 장군의 지도 / 바람의 나침반 / 시간의 모래시계 | 공격·방어·수입·시작 금·시작 병력·해상·회복 보너스 |

## 파일 구조

```
conquest/
  index.html          화면 구성과 스타일
  js/mapdata.js       세계 지도 격자·영토·인접 정보 (자동 생성)
  js/data.js          군주, 아이템, 난이도, 목표
  js/sprites.js       초상화·꼬마 캐릭터·아이콘 도트 생성기
  js/audio.js         칩튠 효과음과 짧은 배경음 (WebAudio)
  js/engine.js        경제·전투·외교·AI (화면과 분리)
  js/worldview.js     2.5D 지도 렌더러, 카메라, 유닛, 애니메이션
  js/castle.js        성 허브 장면
  js/ui.js            대화창, 모달, 상점, 보물창고, 군주 선택/창조
  js/play.js          지도 위 플레이 진행
  js/main.js          장면 전환과 입력
  tools/build-map.mjs 지도 데이터 생성기
  fonts/              갈무리 도트 글꼴 (SIL OFL)
```

## 지도 데이터 다시 만들기

```bash
mkdir /tmp/mapbuild && cd /tmp/mapbuild && npm i world-atlas@2.0.2 topojson-client@3.1.0
cd -  # 저장소로 돌아와서
node conquest/tools/build-map.mjs /tmp/mapbuild/node_modules > conquest/js/mapdata.js
```

Natural Earth 110m 국경을 0.5° 격자로 래스터화하고, 큰 나라는 k-means로 지역 영토(예: 러시아 → 모스크바·우랄·야쿠티아 …)로 나눕니다. 현재 173개국, 272개 영토입니다.
